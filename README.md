# Entre a Noite e a Farda

Site estático pronto para GitHub Pages.

## Arquivos principais

- `index.html`
- `favicon.ico`
- `favicon.png`
- `assets/illustrations`
- `assets/photos`

## Como subir

No GitHub, faça upload dos arquivos extraídos, não do ZIP. A estrutura precisa ficar na raiz do repositório:

```text
index.html
favicon.ico
favicon.png
README.md
assets/
```

Depois vá em **Settings > Pages** e configure:

- Source: Deploy from a branch
- Branch: main
- Folder: /root

Observação: os comentários são salvos localmente no navegador do visitante.
